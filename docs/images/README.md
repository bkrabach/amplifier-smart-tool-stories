# README imagery

`stories-review.jpg` is a browser screenshot of Stories displaying
“The story of Stories,” a presentation generated by the tool itself for the
project README. It shows the live local review interface, not a mockup.

The presentation was generated through the public Stories library using Anthropic
Claude Sonnet 4.6. Its sources were this repository's README, vision, storytelling
coverage and commit history through `35a102d`. The brief asked for the journey from
bundle expertise to a standalone tool, material-first shared review, evidence
safeguards, delivered formats and remaining work. Generation and review do not
constitute independent verification of the project's claims.

The capture frames the opening slide and top review controls, omitting unused
space below the slide. It is captured directly from the browser, with no compositing
or retouching. It excludes browser chrome, credentials, local filesystem paths and
the private authenticated viewer URL. Generated trial state and intermediate outputs
are not part of the repository.
